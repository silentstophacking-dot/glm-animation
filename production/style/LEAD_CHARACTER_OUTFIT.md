# Lead-character outfit study

Owner feedback: the three initial options need a stronger main-character presence. This candidate prioritizes one recognisable colour arrangement and a more distinctive jacket shape, while preserving the current rig, face and proportions.

New opt-in `cobalt-lead` outfit: cropped cobalt jacket with a diagonal opening, asymmetric raised collar, warm gold mock-neck layer, one broad cream chest band, restrained zipper/pocket construction, gold cuff lines, charcoal trousers and cream shoes. The blue/gold contrast is chosen to read against the existing purple/orange sunset lab without adding an all-over glow or numerous accessories.

The equal-height study compares it with the previous teal overshirt, using the same expression, body angle, light and floor baseline; smaller silhouettes check the outline without colour. A second still shows the new outfit in the existing lab at the same frame used for the earlier teal study. This is an original clothing direction, not a claim of complete character identity or visual approval.

Implementation extends the existing garment and palette options. Previous outfits, proofs, animation defaults and Probability Control remain unchanged. This is design-only: the new collar, diagonal front and cuff details require turn/pose/contact review before costume adoption in the acting sequence. No movie or full episode render is needed to review this still candidate.
